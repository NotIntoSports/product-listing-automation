按任务和角色读取资料，不在启动时遍历全部参考文档或脚本源码。

| 当前任务／角色 | 读取内容 |
|---|---|
| 发布、重试、失败回滚及多步批量写入的总控 | [监督流程](references/supervision.md)，负责范围、派发、恢复与验收。平台操作资料交给执行者；证据冲突时再查对应章节。 |
| 被派发的执行者 | 按任务读[天猫操作](references/tmall.md)和[飞书数据](references/feishu.md)，不再派发写入执行者。 |
| 查表、补资料、维护商品或链接 | [飞书数据](references/feishu.md)。简单只读查询可直接执行。 |
| 仅询问哪些链接能发布／核实平台状态 | [天猫操作](references/tmall.md)及相关飞书记录；预检请求不授权提交。 |
| 优化看板、排查统计 | [看板规则](references/dashboard.md)，需要字段定义时查飞书数据。 |
| 明确要求新建或初始化管理表 | [建表流程](references/setup.md)。已有 Base 直接复用。 |

记录发布批次断点时读[状态接口](references/state-api.md)，遇到实际异常才读[恢复排查](references/recovery.md)。只读相关章节；同一智能体已读取且内容未变时无需重复读取。

共同约束：只处理已授权范围，不自行更换店铺、价格、库存或发布方式；已有提交证据先核实，防止重复创建；用户停止／接管优先于自动恢复。发布任务必须核对业务结果，并按[浏览器收尾](references/supervision.md#浏览器收尾)确认控制权释放后交付。其他平台目前只支持资料维护。
