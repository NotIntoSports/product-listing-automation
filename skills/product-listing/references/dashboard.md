# 看板统计与更新排查

仅维护运营看板或排查统计时读取；表和字段定义见[飞书数据](feishu.md#各表写什么)。

- 发布进度以「上架链接 → 发布状态」为数据源，按链接记录 ID 计数；商品档案中的价格、备注或上架状态不能替代链接进度。异常待办以「上架失败 → 处理状态」统计，标清异常记录数；同一链接可能多条异常，不能称为失败链接数。
- 覆盖业务链接总数、待提交、待核实、已入仓、已上架及受阻链接，排除验收草稿。已入仓不等于出售中；平台拒绝与未提交暂停分开。明确历史／本批次口径，本批次用固定记录范围，不用总表数量冒充。
- 图表直接引用源表聚合，不写死数字或复制一次性汇总表。未知、空状态先显示说明；核对互斥分组与业务总数，避免筛选静默漏项，不擅自归为成功或失败。
- 排查顺序：源表当前字段与完整范围 → 组件数据源、筛选、分组及聚合 → 计算结果对账 → 页面刷新。只有源表和计算正确、页面仍旧时，才考虑缓存或刷新。
- 改价格或备注不必然改变发布进度；看板不会自行查询天猫。异常已解决但未关闭时先查证据，不为改善统计清除异常。
- 布局以少量关键指标、状态与异常分布及统计口径为主，不画大量每标题数值为 1 的图。用当前工具支持的组件，修改前读配置、完成后验算；有浏览器条件时检查渲染并按技能收尾要求释放控制。
