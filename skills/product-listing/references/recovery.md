# 普通中断恢复排查

先读持久化状态与当前页面，再选择对应动作。修复后更新实际断点，回到[监督循环](supervision.md#监督循环)继续。只有有证据的当前障碍才能标记阻塞，不能以「发生意外」结束。

| 现象 | 恢复与验收 |
|---|---|
| 窗口最小化、截图失败 | 在原任务空间内，用当前工具文档支持的窗口恢复能力恢复正常窗口，再取新快照；不要先要求用户恢复。改变窗口后旧定位失效，重新观察。 |
| 元素过期、遮挡、布局或 iframe 改变 | 读取当前页面／弹窗与加载状态，处理可关闭的遮挡，按新定位继续；不能重复使用旧引用。 |
| 点击图片后槽位仍空 | 检查选择勾选状态、当前槽位、尺寸要求和确认按钮。需要裁剪时用平台已有裁剪工具按该槽位要求处理；确认弹窗关闭后目标槽位已有正确图片。上传或点击不等于绑定。 |
| 页面跳转后正文为空、读取失败 | 等待可观察的加载状态，重读 URL 与页面；先保存成功 URL／回执中已取得的商品 ID。提交意图已保存却结果不明时先查证，不能再次点击发布。 |
| 子智能体退出、一次工具异常 | 总控检查未完成工具调用和落盘断点，主动唤醒同一执行者续跑。替换前确认原执行者停稳，重新分配 generation。 |
| 飞书可读但写入被拒 | 核对当前身份、目标 Base、表及实际授权；若已有同一 Base 的已配置授权身份可用，按工具文档使用，不因一种身份报错就断言所有身份无权。不得获取新权限或泄露令牌。 |
| 写入成功但紧接着读到旧值 | 保留写入回执及版本，用有界重读检查同一记录和字段的新版本；一次旧读不等于写入失败。持续不一致再诊断，并保留已成功的商品回执。 |
| 参数过长、spawn 失败、中文损坏 | 检查实际进程退出码与 stderr；用 UTF-8 脚本／JSON 文件和工具支持的文件输入，按实际限制分批。先检查本机可执行文件与当前参数，不硬编码另一台机器的磁盘路径。 |
| 平台处理超出预计时间 | 记录查询范围、商品 ID、时间和状态，调整核实节奏，继续其他链接。耗时不能证明拒绝；已提交成功不重新发布。 |
| 任务空间丢失、用户接管、验证挑战 | 遵守当前浏览器文档和用户授权；不能换空间或通道绕过控制权。确需用户动作时，完成独立工作并按监督流程交还现场。 |

失败回滚只修改用户授权的失败数据，并保留原值、历史报错及平台提交证据。开始前逐条核实是否实际已创建商品；已经创建的转入核实／回写，不把它们清成待发布后重复创建。回滚按记录 ID 去重，写后读回；回滚完成继续重试队列，不停在「已重置」等用户再次说继续。

恢复不能编造业务值：缺失统一售价、归属、库存、单位等仍按平台和飞书流程判断；普通页面异常不写成商品预检失败。共同阻塞只影响明确匹配的记录，不传播到整批无关商品。
