# 初始化飞书商品上架管理

用已授权的飞书账号或应用创建 Base，或者在用户指定的空 Base 内初始化。先查同名 Base 和目标位置，确认是新建还是复用。重跑时按表名和字段名补缺，发现同名字段类型或关联目标不一致时报告冲突，保留现有数据。

## 表和关联

按[字段归属](feishu.md#各表写什么)创建八张表。先建商品档案，再建 SKU、尺码表、商品素材和上架链接，最后建链接 SKU、链接素材和上架失败。

| 表 | 主字段 | 关联字段 |
|---|---|---|
| 商品档案 | 商品标题 | — |
| SKU | SKU编码 | 关联商品 → 商品档案 |
| 尺码表 | 尺码 | 关联商品 → 商品档案 |
| 商品素材 | 文件名 | 关联商品 → 商品档案 |
| 上架链接 | 链接编号 | 关联商品 → 商品档案，每条链接只关联一款 |
| 链接 SKU | 链接SKU编号 | 上架链接 → 上架链接，基础SKU → SKU |
| 链接素材 | 选图编号 | 上架链接 → 上架链接，商品素材 → 商品素材 |
| 上架失败 | 商品标题 | 上架链接 → 上架链接 |

统一售价（元）用数字字段，仅建在商品档案。库存、原始尺码量值、素材和槽位顺序用数字字段，素材附件用附件字段，商品 ID、类目 ID、货号及 SKU 编码用文本字段。保留尺码原始单位，天猫 SKU 上市年月用年月值。

## 工作视图与验收

上架链接的物流字段按[链接配置](feishu.md#链接配置)创建：运费承担方式、发货时间用单选，发货地用文本；运费模板在取得真实店铺清单后配置单选或关联表，未取得时允许留空。发布方式与发布状态分开保存，不预填某一店铺、地区或时效作为通用默认值。

1. 上架链接创建「待发布」和「提交后待跟进」。前者包含待发布、待补资料和业务草稿，后者包含「已提交，预检中」和「已提交，待核实」。验收草稿单独筛选。上架失败创建「未解决」视图，筛掉已解决。
2. 按[看板统计规则](feishu.md#看板统计与更新排查)建紧凑的运营总览，展示业务链接总数、待提交、待核实、已入仓、已上架及受阻链接，配状态分布与异常分布。直接引用源表聚合，验收草稿不计入正式指标；异常记录数与受阻链接数分别标明，拒绝与暂停不能混称提交失败。
3. 读回检查表、字段类型、关联目标和视图筛选，交付新 Base 链接及缺少的权限。业务资料由使用者补齐。若需要让其他账号协作，由负责人按职责给出查看或编辑权限。
